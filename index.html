    🚀 GitHub Deployment Guide

    Follow these standard terminal commands to deploy this project to GitHub:

    # 1. Initialize git repository
git init

# 2. Add files and commit
git add .
git commit -m "feat: initial task tracker application setup"

# 3. Create branch & connect remote repository
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/task-tracker.git

# 4. Push code to GitHub
git push -u origin main

    To activate GitHub Pages: Go to Repository Settings -> Pages -> Source: select main branch -> Save.
